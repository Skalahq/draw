# Domain docs

Draw is single-context. Before exploring the domain, read root `GLOSSARY.md` and relevant decisions in `docs/adr/`. If either is absent, proceed silently; `/domain-modeling` creates them as terms and decisions settle.

Use glossary terms in issues, designs, and tests. Flag terms that need a definition. If a proposal contradicts an ADR, name that ADR and explain why the decision should be reopened.
